# Работа администратора

## Вход

UI запускает Discord OAuth2 через `/api/auth/discord/login`. После callback backend выдаёт session cookie, а `/api/auth/me` возвращает пользователя и только те guild, где он является owner либо имеет Administrator/Manage Server.

Если список пуст, установите бота в подходящий сервер или проверьте права текущего Discord-пользователя.

## Создание маппинга

1. Откройте `/app` и выберите сервер.
2. Укажите trigger:
   - Unicode emoji: `😊`;
   - текстовый shortcode: `smile` или формат, поддерживаемый текущим detector;
   - custom emoji сервера: например `:party_blob:`.
3. Выберите PNG, JPEG или WEBP до 512 КБ.
4. Загрузите файл.

Маппинг принадлежит выбранному guild. Несколько изображений с одинаковым trigger образуют группу; при сообщении бот случайно выбирает одно из них.

## Preview

В списке отображаются:

- custom emoji сервера и его читаемое имя, если Discord metadata доступна;
- Unicode/text trigger как fallback;
- preview каждого загруженного стикера;
- количество стикеров в группе;
- состояния загрузки и недоступного preview.

Недоступный preview не удаляет сам маппинг и не блокирует кнопку удаления. Внутренние MinIO bucket/object key пользователю не показываются.

## Default stickers

Глобально доступны пять встроенных trigger: 😊, ❤️, 🎉, 👍 и 🔥. Они используются, пока в конкретном guild нет пользовательского маппинга для того же нормализованного emoji.

Defaults находятся в classpath приложения, не записываются в PostgreSQL и не входят в `GET /api/mappings/{guildId}`. Их metadata выдаётся отдельным endpoint `/api/stickers/default`.

## Удаление

Удаление требует явного подтверждения в UI. Backend проверяет права на guild владельца маппинга, удаляет запись и связанный объект. После ответа `204` элемент исчезает из списка.

## Что именно заменяется

Заменяется только сообщение, которое detector считает одним emoji без другого текста. Примеры:

| Сообщение | Результат |
|---|---|
| `😊` | заменяется при наличии custom/default sticker |
| `Hello 😊` | игнорируется |
| `😊❤️` | игнорируется |
| emoji без маппинга | остаётся без изменений |
| сообщение бота | игнорируется |
| direct message | игнорируется |

Emoji-варианты и модификаторы нормализуются по правилам приложения и могут требовать отдельного маппинга.
