# Bigmoji

Bigmoji — Discord-бот, который превращает сообщение, состоящее ровно из одного emoji, в крупное изображение-стикер. Администратор сервера может загрузить собственные изображения и связать их с Unicode emoji, текстовыми shortcode или custom emoji сервера.

## Как это работает

1. Пользователь отправляет в Discord сообщение только с одним emoji, например `🔥`.
2. Бот нормализует emoji и ищет пользовательские маппинги для текущего Discord-сервера.
3. Если пользовательского маппинга нет, проверяется встроенный набор: 😊, ❤️, 🎉, 👍 и 🔥.
4. Изображение отправляется в тот же канал через webhook от имени и с аватаром автора. Discord показывает стандартный значок бота.
5. Исходное сообщение удаляется только после успешной отправки изображения.

Сообщения с обычным текстом, несколькими emoji, сообщения самого бота и личные сообщения не заменяются.

## Возможности

- независимые наборы стикеров для каждого Discord guild;
- несколько стикеров на один emoji со случайным выбором;
- встроенный fallback-набор без первоначальной настройки;
- Discord OAuth2 и проверка права Manage Server/Administrator;
- загрузка, просмотр и удаление маппингов через web UI и REST API;
- preview загруженных стикеров и custom emoji;
- доставка файлов через Discord API, без публикации MinIO URL в чат;
- PostgreSQL для метаданных, MinIO для файлов и in-memory cache для быстрого поиска;
- отдельный React UI, разворачиваемый в Docker;
- health endpoint, Swagger UI и диагностическое логирование.

## Ограничения

- загрузка принимает PNG, JPEG и WEBP размером до 512 КБ;
- webhook-отправка требует `MANAGE_WEBHOOKS`; при отсутствии права используется имя самого бота;
- Discord-боту также нужны чтение истории, отправка сообщений, вложения и удаление исходного сообщения;
- fallback не применяется при ошибке доступа к данным: исходное сообщение остаётся без изменений;
- управление доступно только guild, которыми текущий Discord-пользователь вправе управлять.

## Технологии

Backend: Java 21, Spring Boot, JDA 5, PostgreSQL, MinIO, Gradle.  
Frontend: React 19, TypeScript, Vite, nginx.  
Развёртывание: Docker Compose.
